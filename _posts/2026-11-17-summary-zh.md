### [顾全全团队 NovaAtom-Lite 在 FoldBench 超越 IsoDDE](https://www.woshipm.com/ai/6494457.html) ⭐️ 9.0/10 [人工智能与大模型]

**核心要点速览**:
- Geodesic Intelligence 发布 NovaAtom-Lite 模型，在 FoldBench 基准测试中击败 DeepMind 的 IsoDDE，宣称将癌症药物研发周期从 10 年压缩至 4 年。
- 该模型采用全原子结构预测技术，通过引入条件约束与提示机制，实现抗体 - 抗原及蛋白质 - 配体结合界面的精确三维坐标预测。
- 在抗体 - 抗原预测上，NovaAtom-Lite 的 DockQ 成功率比 AlphaFold 3 高出 31 个百分点，在极高精度标准下是 AF3 的 2.2 倍。

**深度内容详析**:
NovaAtom-Lite 是顾全全创立的 Geodesic Intelligence 公司推出的全原子结构预测模型，旨在解决药物研发中分子‘咬合’的难题。传统药物研发需湿实验逐一试错，周期长达 10-13 年且成功率不足 5%。NovaAtom-Lite 的核心逻辑是在计算机中模拟分子间相互作用，输入蛋白质、核酸及小分子配体序列，直接输出每个重原子的三维空间坐标，精度达埃（Å）级别。与仅输出轮廓的旧模型不同，NovaAtom-Lite 引入了‘条件约束与提示’功能，允许用户输入共价键或已知结合口袋信息，模型将其作为参考线索灵活处理，而非死板约束。在 FoldBench 这一包含 1522 个新结构数据的严苛基准中，NovaAtom-Lite 在抗体 - 抗原结合预测（DockQ 分数）上大幅领先 IsoDDE，证明了其在复杂生物分子界面预测上的突破性能力。

### [开源项目 terminal-mac 为 AI Agent 提供独立 macOS 沙箱](https://www.woshipm.com/ai/6494316.html) ⭐️ 9.0/10 [人工智能与大模型]

**核心要点速览**:
- terminal-mac 项目已在 GitHub 获得 2600+ stars，X 平台发布即获 70 万次浏览，解决了 AI Agent 操作主机系统的安全痛点。
- 该项目基于苹果官方 Virtualization 框架构建真实 macOS 虚拟机，并通过 Kitty/iTerm2 协议将渲染画面嵌入终端窗口，同时内置 MCP 服务器提供 Agent 操作接口。
- 虚拟机与主机仅共享指令 JSON 文件和只读辅助工具目录，严格隔离用户的主目录、剪贴板、麦克风及摄像头，防止误删文件或数据泄露。

**深度内容详析**:
terminal-mac 是一款专为 Apple Silicon Mac 设计的开源工具，旨在解决 AI Agent（如 Claude Code）在操作本地计算机时可能引发的安全风险。其核心架构包含两个关键创新：首先，它利用苹果官方 Virtualization 框架启动一台完全独立的真实 macOS 虚拟机，拥有独立的桌面、文件系统、账号及应用，确保 Agent 的误操作仅影响虚拟机内部，而不会波及宿主系统。其次，项目重构了传统虚拟机的交互方式，不再需要额外的窗口切换，而是利用 Kitty 图形协议或 iTerm2 内联图像协议，将虚拟机的屏幕实时渲染嵌入到终端面板中，实现命令、日志与操作画面的同屏监控。此外，项目内置 MCP 服务器，允许 Agent 通过截图、点击、拖拽等指令控制虚拟机，且主机与虚拟机间仅共享用于传输指令的 JSON 文件和只读的辅助工具目录，彻底切断了剪贴板、麦克风等敏感资源的共享路径，为 AI Agent 提供了一个既具备完整操作能力又具备高安全隔离性的沙箱环境。

rss · 人人都是产品经理日榜 · 11月16日 03:12
