斯隆数字巡天计划（SDSS）与 eROSITA X 射线望远镜协同发布了一幅覆盖全天的 50 万类星体黑洞分布图，数据采集周期为 1.5 年。该成果使已知 X 射线源数量翻倍至 200 万。 该图谱通过揭示 50 万类星体黑洞的空间分布规律，为研究星系演化与暗物质作用机制提供了关键数据。其跨学科的数据分析方法（天文与基因组学）具有范式意义。 数据采集基于 SDSS 3.5 米光学望远镜与 eROSITA X 射线望远镜的协同观测，时间跨度 1.5 年，定位精度达 90%。主要局限包括南方天空观测不完整，以及 X 射线源检测可能存在的样本选择偏差。

### [sub2api OAuth 高危账户接管漏洞披露](https://github.com/Wei-Shaw/sub2api/issues/5350) ⭐️ 9.0/10 [技术]

sub2api v0.1.171 及之前版本存在严重 OAuth 账户接管漏洞（CVSS 8.8），攻击者仅凭受害者注册邮箱即可绕过密码和验证码验证，完全控制 API 密钥及账户资源。 该漏洞暴露了 OAuth 核心身份绑定机制的安全缺陷，可能导致大规模 API 密钥被盗及未经授权的账户资金操作，凸显 OAuth 会话管理及身份验证流程的严重漏洞。 该漏洞源于 OAuth pending session 流程中 existingUser 分支的身份验证缺陷，攻击者通过未验证的会话逻辑将自身 OAuth 身份绑定到受害者账户，无需用户交互即可完成身份绑定。

telegram · zaihuapd · 8月7日 14:59

**背景**: OAuth 2.0 是第三方应用访问服务器资源而无需共享凭证的授权框架。会话管理（如 pending exchange）对防止身份绑定攻击至关重要，但许多实现忽视了严格的会话过期策略和多因素验证。
