### [Qwen 3.8：阿里巴巴 2.4 万亿参数开源模型](https://twitter.com/Alibaba_Qwen/status/2078759124914098291) ⭐️ 9.0/10 [技术]

阿里巴巴宣布了 Qwen 3.8，一个拥有 2.4 万亿参数的大语言模型，并承诺以开放权重发布。这一宣布紧随月之暗面（Moonshot AI）发布 2.8 万亿参数的 Kimi K3 模型之后。 这标志着开源权重大语言模型竞赛的重大升级，中国公司发布的模型在规模上可与专有系统媲美。如此大规模开放模型的可用性可能加速 AI 研究和部署，特别是对于需要本地推理的应用。 Qwen 3.8 拥有 2.4 万亿参数，但尚未公布任何基准测试结果。预览版已通过阿里巴巴的 Token 计划提供，开放权重预计很快发布。

### [Claude Code 采用 Rust 重写的 Bun](https://simonwillison.net/2026/Jul/19/claude-code-in-bun-in-rust/) ⭐️ 8.0/10 [技术]

Anthropic 的 AI 编程工具 Claude Code 现在使用 Bun 作为其 JavaScript 运行时。Bun 已从 Zig 语言重写为 Rust 语言，这是一次重大的工程转变。 这一决定凸显了系统编程中手动内存管理（Zig）与自动安全（Rust）之间的权衡。它还引发了关于 AI 在大规模代码重写中的作用以及开源项目在被 Anthropic 等公司收购后的治理问题的讨论。 Bun 从 Zig 到 Rust 的重写是在不到一个月内合并的一个大型 PR 中完成的，据称有 AI 辅助。Claude Code 附带了 Bun v1.4.0 的预览版，而最新的公开发布版是 v1.3.14。

hackernews · tosh · 7月19日 10:03 · [社区讨论](https://news.ycombinator.com/item?id=48966569)

**背景**: Bun 是一个集 JavaScript 运行时、打包器和包管理器于一体的工具，旨在作为 Node.js 的直接替代品。它最初是用 Zig 语言编写的，Zig 是一种需要手动内存管理的系统编程语言。Rust 是另一种系统语言，通过其所有权模型提供内存安全。Claude Code 是 Anthropic 的 AI 编程助手，帮助开发者编辑代码、运行命令和发布软件。

SpaceX 股价首次跌破 135 美元的发行价，周五收于 123.99 美元。过去一个月，做空者账面获利约 40 亿美元。 此次下跌表明 SpaceX 股票在上市后不久就面临巨大抛压，影响投资者情绪，并可能波及公司估值。高比例的空头头寸反映出市场的看空预期。 约 9 亿股最早将于 8 月随部分 IPO 前投资者锁定期到期进入流通，增加供给。同时，SpaceX 的债券收益率上升，30 年期债券收益率从 6.7% 升至 7.4%。

**背景**: SpaceX 是埃隆·马斯克创立的航空航天制造商和太空运输公司。该公司近期通过首次公开募股（IPO）上市，发行价为每股 135 美元。股价最初上涨，但随后因锁定期到期和债券市场疲软等因素下跌。
