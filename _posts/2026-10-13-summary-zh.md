### [杨立昆提出分层推理，反对 Agent 与 RSI 叙事](https://www.tmtpost.com/8165030.html) ⭐️ 9.0/10 [人工智能与大模型]

**核心要点速览**:
- 杨立昆发布 H-JEPA 模型，在 Visual AntMaze 任务中将成功率从单层 18% 提升至三层 73%，挑战当前 Agent 与 RSI 范式。
- H-JEPA 采用分层世界模型架构，高层进行宏观规划，底层执行微观动作，通过抽象层级压缩计算量而非增加步数。
- 该模型无需外部奖励信号或像素重建，仅通过预测潜在表征空间中的状态转移进行训练，且层数过多会导致性能下降。
- 杨立昆指出当前 Agent 依赖试错与奖励机制效率低下，主张在动作执行前通过分层推理预判连锁反应。

**深度内容详析**:
杨立昆（Jeffrey Dean）最新提出的 H-JEPA（Hierarchical JEPA）模型旨在从根本上挑战当前 AI 领域关于 Agent 和 RSI（Reasoning as Search）的主流叙事。该模型基于其早期的 JEPA（联合嵌入预测架构）理念，但引入了分层机制。与现有视频生成模型逐帧预测不同，JEPA 将视觉输入压缩为抽象向量，在潜在空间中预测未来状态。H-JEPA 的核心创新在于将多个 JEPA 模块堆叠，每一层拥有独立的观察编码器和动作编码器，且每层预测的时间跨度不同：底层关注短期细节，高层关注长期宏观目标。在规划时，高层先设定粗略目标，逐层细化至底层输出具体动作，这种“从纽约去巴黎”的分层逻辑有效解决了单层模型在长任务中误差累积和搜索空间爆炸的问题。实验数据显示，在 Visual AntMaze 迷宫任务中，三层 H-JEPA 的成功率高达 73%，远超单层模型的 18%。然而，层数并非越多越好，Push-T 任务显示两层表现最佳，三层四层后性能反而下降，因为高层缺乏足够的训练数据迁移。杨立昆强调，H-JEPA 无需外部奖励信号或像素重建，仅通过表征空间预测训练，这与当前依赖试错和奖励函数的 Agent 形成鲜明对比。

rss · 钛媒体 · 10月12日 08:13

**背景**: JEPA 是一种自监督学习架构，通过预测输入数据的抽象嵌入而非重建原始像素来学习。分层推理模仿人类大脑在不同时间尺度和抽象层级上处理信息的方式，旨在解决单层模型在长任务中效率低下的问题。
