### [唐杰：Scaling Law 新标尺从参数转向算力](https://www.tmtpost.com/8112064.html) ⭐️ 9.0/10 [人工智能与大模型]

**核心要点速览**:
- 智谱 AI 创始人唐杰提出 Scaling Law 的核心指标应从“参数量”转向“有效算力（FLOPs）”，认为后者才是决定模型智能水平的真正标尺。
- 通过对比 Switch-C（1.6 万亿参数）与 T5-XXL（110 亿参数）在相同 FLOPs 下的表现，论证了单纯堆砌参数仅增加“知识仓库容量”，无法提升推理深度。
- 行业实践已从 Chinchilla 定律（参数与数据同步增长）演变为“更小模型、更长训练”策略，以优化推理成本并提升每参数 Token 数。
- MoE 架构（混合专家）通过稀疏激活将总参数与激活参数解耦，使得在固定算力预算下，模型能承载更多知识但单次推理效率更高。

**深度内容详析**:
智谱 AI 创始人唐杰在最新分析中颠覆了行业对 Scaling Law 的传统认知，指出参数量仅是知识的存储仓库，而真正驱动智能的是计算量（FLOPs）。文章通过回顾 2021 年 Google 发布的 Switch-C 模型（1.6 万亿参数）与 T5-XXL（110 亿参数）的对比，揭示了单纯扩大参数规模的局限性。尽管 Switch-C 在知识检索任务上表现优异，但在需要多步推理的 ARC Challenge 任务中却落后于 T5-Base，这证明了参数膨胀仅增加了模型的“记忆量”，并未提升其“思考深度”。唐杰进一步区分了总参数、激活参数与 FLOPs 的概念：总参数决定容量上限，激活参数决定单次调用的能力，而 FLOPs 则是衡量模型实际推理能力的真实标尺。这一观点挑战了早期 Kaplan 定律中参数优先增长的假设，并呼应了 Chinchilla 定律中参数与数据配比优化的结论，强调未来模型架构应追求在固定算力预算下最大化有效推理深度，而非盲目追求万亿参数规模。

**背景**: Scaling Law 最初由 Kaplan 等人提出，认为模型参数、数据和计算量的增长会导致性能平滑提升。早期行业普遍认为参数越多越强，但后续研究发现，在固定算力下，参数与数据的配比及激活效率才是关键。

### [FreeToken 开源：单卡 RTX 5090 跑满血 DeepSeek V4Flash](https://mp.weixin.qq.com/s/Hz-mm3Izi8M2uMZHL3wx5w) ⭐️ 9.0/10 [人工智能与大模型]

- FreeToken 系统开源，实现单卡 RTX 5090 运行满血版 DeepSeek-V4-Flash 284B 模型，首 Token 延迟降低 42-58%，多轮交互延迟减少 65-80%。
- 该技术通过全栈协同设计，利用双缓冲预取、动态带宽感知及状态复用机制，打破消费级硬件运行 MoE 大模型的瓶颈。
- 系统支持 Windows/Linux 桌面端与 CLI 部署，无需将模型权重完全加载至显存，仅需约 32GB 显存配合 192GB 内存即可稳定运行。

**深度内容详析**:
FreeToken 是由 UC Berkeley、MIT 等顶尖机构联合开发的边缘原生 MoE 推理系统，旨在解决消费级硬件运行大规模混合专家模型（MoE）的难题。传统方案因 PCIe 带宽瓶颈和显存限制，导致 MoE 模型在长 Prompt 处理时性能急剧下降，甚至因专家权重加载过慢而卡死。FreeToken 的核心创新在于重新定义了端侧异构硬件的调度逻辑，采用全层双缓冲（Double-Buffered Prefill）技术，在 GPU 计算当前层的同时，后台通过 PCIe 流式预取下一层的专家权重，消除了 I/O 阻塞。此外，系统引入动态带宽感知机制，能根据总线负载自动调整 CPU 与 GPU 的计算比例，并在显存不足时无缝收缩 LRU Cache，实现平滑降级而不中断服务。这种软硬件协同设计使得 RTX 5090 单卡能够高效运行 DeepSeek-V4-Flash 等超大参数模型，将推理速度提升至交互级实用水平。

rss · 机器之心 · 8月22日 10:38

**背景**: Mixture of Experts（MoE）是一种通过稀疏激活来加速推理的模型架构，但完整专家池的内存需求巨大，远超普通显卡显存。传统推理框架在处理长上下文时，需逐层从系统内存拉取专家权重，导致严重的 I/O 阻塞和延迟。FreeToken 通过软硬件协同调度，解决了这一瓶颈。

### [美图提出 CFT 一致特征传输重打光新方案](https://mp.weixin.qq.com/s/Y0XQrgDqd1lIVko_YVkuQQ) ⭐️ 8.0/10 [人工智能与大模型]

**核心要点速览**:
- 美图影像研究院在 ECCV 2026 提出 Consistent Feature Transport (CFT)，将人像重打光重构为光照一致的特征传输问题。
- CFT 基于 Rectified Flow 框架，通过 L1/L2/L3 三项损失函数联合建模，显式学习源图与目标图间的线性光照变换速度场。
- 相比现有扩散模型方案，CFT 在复杂光照（多色温、空间阴影）下显著提升了内容一致性与物理合理性，且无需冗长提示词即可在 Picchi 等产品上线。

**深度内容详析**:
美图影像研究院针对现有扩散模型重打光方案在复杂光照下易导致阴影错乱、人脸变形及内容不一致的问题，提出了 Consistent Feature Transport (CFT) 新方案。该研究将重打光任务重新定义为“光照一致的特征传输”问题，而非泛化的图像翻译。CFT 在 Rectified Flow 框架下，建立了噪声、源图、目标图三个分布的联合建模机制。其核心创新在于利用无反演编辑的平行四边形法则，构造源图到目标图的直接传输路径，通过 L3 损失项（CFT 核心）监督“同光照变换但不同内容”的图像对，从而剥离内容差异，仅学习可复用的光照特征位移。实验表明，完整 CFT（L1+L2+L3）在 SSIM、PSNR、FID 等指标上均优于仅用 L1 或随机配对的方案，且在多光源交互等困难场景下展现出更优的一致性。此外，团队构建了覆盖 14 类光照效果的大规模数据集以支撑训练，并验证了该方法在风格迁移任务上的泛化能力。

rss · 机器之心 · 8月22日 06:00

**背景**: 人像重打光（Relighting）旨在改变图像光照而不改变主体内容，但传统方法常因光照建模不足导致阴影方向错误或人脸结构扭曲。当前主流方案包括控制信号驱动、本征分解驱动及直接图到图翻译，均存在在复杂光照下精度不足或内容不一致的缺陷。

### [LoopsBench：面向长周期任务的 Coding Agent 新评测标准](https://mp.weixin.qq.com/s/A8zaVwd6qm-T-W-080AXhg) ⭐️ 8.0/10 [人工智能与大模型]

**核心要点速览**:
- 微软与南京大学团队发布 LoopsBench，旨在解决 Coding Agent 在长周期软件开发任务中持续执行能力的评测难题。
- 该评测框架将任务重构为依赖有向无环图（Dependency DAG），包含 112 个长周期任务及超过 5300 个可验证的开发单元。
- 核心机制从传统的 Harness Engineering（工具交互）转向 Loop Engineering（循环工程），强调对任务依赖、状态维护和回归控制的评估。
- 数据来源涵盖大学课程项目、真实开源项目的连续 Pull Request 以及研究论文的演化链，确保任务具有真实的工程依赖结构。
