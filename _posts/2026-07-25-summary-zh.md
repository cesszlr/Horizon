### [Anthropic 发布 Claude Opus 5：强大 AI 模型，无数据保留要求](https://www.anthropic.com/news/claude-opus-5) ⭐️ 10.0/10 [技术]

Anthropic 发布了 Claude Opus 5，这是一款接近 Claude Fable 5 前沿智能但价格减半的新 AI 模型，且对通用访问无数据保留要求。它在编码和知识工作评估（如 Frontier-Bench 和 GDPval-AA）上达到了最先进水平。 Claude Opus 5 的重要性在于它提供了接近前沿的智能，且没有像 Claude Fable 那样的数据保留要求，适合有严格数据政策的组织。它在编码和知识任务上的强劲表现也使其成为开发者和研究人员的多功能工具。 Claude Opus 5 是 Opus 系列的最新版本，继 Claude 4.5 之后，专为日常使用设计，效率更高。它在全栈应用构建方面超越了之前的 Opus 模型，尤其是在前端动画、游戏和 3D 工作上表现突出，但在网络安全任务上仍落后于 Mythos 5。

hackernews · alvis · 7月24日 16:57 · [社区讨论](https://news.ycombinator.com/item?id=49038433)

**背景**: Claude 是 Anthropic 开发的一系列大型语言模型，采用宪法 AI 训练以提高伦理和法律合规性。从 Claude 3 开始，每一代都发布三个规模：Haiku、Sonnet 和 Opus。2026 年，Anthropic 还发布了 Mythos 和 Fable 模型，其中 Fable 是 Mythos 的版本，具有更严格的安全保障。Claude Opus 5 是最新的 Opus 模型，以更低的价格提供接近前沿的智能。

Black Forest Labs 发布了 FLUX 3，这是一个支持图像、视频、音频和动作预测的多模态模型，并与 mimic 合作推出了 FLUX-mimic，这是一个视频动作模型，能从视频生成中提取世界表征用于机器人控制，已在奥迪进行测试。 这代表了将生成式视频模型应用于机器人领域的范式转变，有望让机器人从互联网规模的视频数据中学习复杂的物理任务，而无需大量手动编程。 FLUX 3 在统一的架构中联合训练多种模态，FLUX-mimic 利用这一骨干网络结合 mimic 的机器人学习专长实现灵巧操作，但其表征可能不如专门方法那样解耦。

### [安全摄像头登录页面内含硬编码 GitHub 管理员令牌](https://hhh.hn/hanwha-github-token/) ⭐️ 8.0/10 [技术]

发现一款韩华（Hanwha）安全摄像头的登录页面中嵌入了硬编码的 GitHub 个人访问令牌，且该令牌拥有管理员权限，可能导致设备的源代码仓库面临未授权访问风险。 此漏洞凸显了物联网设备中普遍存在的安全问题，硬编码凭据可能导致供应链攻击并危及内部开发基础设施。这凸显了在设备固件开发中进行严格安全审计和改进实践的必要性。 该令牌出现在登录页面的源代码中，可授予对 GitHub 仓库的管理员级访问权限。该摄像头很可能为韩华型号，攻击者可利用此令牌修改固件或窃取专有代码。

hackernews · hhh · 7月24日 11:54 · [社区讨论](https://news.ycombinator.com/item?id=49034292)

**背景**: GitHub 个人访问令牌用于对 GitHub API 和仓库进行身份验证。将令牌等凭据硬编码在源代码中是一种已知的安全风险，因为任何能访问代码的人都可以使用它们。物联网设备通常缺乏健全的安全措施，因此容易受到此类暴露的影响。

### [英伟达、微软、Meta 警告勿过度监管开放权重 AI](https://www.cnbc.com/2026/07/24/nvidia-microsoft-meta-open-weight-ai-models.html) ⭐️ 8.0/10 [技术]

英伟达、微软和 Meta 联合致信美国政府，警告不要过度监管开放权重 AI 模型，认为此举可能损害美国在 AI 领域的领导地位。 这封联合信函代表了科技行业对开放权重模型潜在监管的重大抵制，开放权重模型对 AI 研发至关重要。这场辩论的结果可能影响 AI 创新和开放与封闭方法之间竞争的未来。 这封信特别针对开放权重模型，这类模型发布训练后的神经网络参数，而非同时发布代码和数据的完全开源模型。这些公司认为过度监管会将 AI 研发推向海外，有利于外国竞争对手。

hackernews · louiereederson · 7月24日 13:32 · [社区讨论](https://news.ycombinator.com/item?id=49035303)

**背景**: 开放权重 AI 模型是指公开发布训练后参数（权重）的模型，允许开发者在自己的硬件上运行和微调。这与完全开源模型（同时发布训练代码和数据）以及仅提供 API 访问的封闭模型不同。开放权重模型已成为 AI 政策的关键战场，支持者认为它们使 AI 访问民主化，批评者则警告它们可能在缺乏保障措施的情况下被滥用。
